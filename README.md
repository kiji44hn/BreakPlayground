# **BreakPlayground** 🎮  
**~ 光、祈り、調和が織りなす幻想的な物理演算体験 ~**

---

## 📝 **プロジェクト概要**  
**BreakPlayground** は、儚い「祈り」と「魂の循環」をテーマにした2Dアクションミニゲームです。  
神殿を舞台に、地上から立ち上る生命の息吹、天から降り注ぐ淡い光、そして魂が天へと昇る流れを表現。破壊と再生の繰り返しが、静寂と調和の中で行われる祈りのような体験を提供します。

このプロジェクトでは以下を探求しています：
- **愛と調和が包む空間**
- **魂の循環と光の息吹**
- **祈りの中で感じる浄化と再生**

---

## ⚙ **使用技術**  
- **Unity (バージョン: 2020.3.48f1)**  
- Rigidbody2D / Collider2D による物理演算  
- タグベースのオブジェクト管理と動的制御  
- **PostProcess演出**: Bloomによる柔らかな光の表現  
- ピアノ音とのシンクロに基づくインタラクション設計  

---

## 🌌 **作品を通じて伝えたいメッセージ**  
本作品は「祈り」を題材としており、神殿の静けさと調和の中で、以下のテーマを表現しています：

1. **背景と神殿の選定**  
   アトリエ風サイトとリンクした背景として、愛と調和を象徴する「神殿」を舞台に設定しました。神殿は、人、神、動物を繋ぐ存在として選ばれました。

2. **生命の息吹と光の演出**  
   - 地上から湧き出る光のエフェクトで、「生命のエネルギー（息吹）」を表現。  
   - ブロックに当たる際のエフェクトにより、天から降る淡い光を再現。  
   - 淡いピンク色は「与える愛」を象徴しています。

3. **魂と愛の循環**  
   ボールは「魂」を表現し、天へ向かう際に地上に愛を残していく流れを示しています。このサイクルが、全体の調和を支えています。

---

## 🎮 **プレイ方法**  
1. **スペースキーでボールを発射**（息吹の放出）。  
2. ボールをブロック（魂）に当てると、ブロックは霧散し光となる。  
3. ボールは2～5秒ごとに初期位置へ戻り、ピアノ音の調べに合わせて再び発射可能。  

🔸 **プレイ体験**：  
淡い光と音の中で、祈りと愛の循環を感じることができます。
