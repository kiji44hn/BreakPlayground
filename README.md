# **BreakPlayground** 🎮  
**~ 光の息吹と祈りが調和する、幻想的な物理演算体験 ~**

---

## 📝 **プロジェクト概要**  
**BreakPlayground** は、儚い「魂の旅路」を描いた2Dアクションミニゲームです。  
地上から立ち上る生命の息吹、天から降り注ぐ淡い光の粒、それらが織り成す神殿のような世界で、ブロック（魂）との交わりを体験します。破壊と再生の繰り返しが、まるで祈りの調べの中で行われる清らかな儀式のようです。  

このゲームは、以下のようなテーマを探求しています：  
- **息吹の輝きと、天へ昇る魂の静けさ**  
- **光の粒に包まれた調和の感覚**  
- **ピアノ音が生み出す浄化のひととき**  

---

## ⚙ **使用技術**  
- **Unity (バージョン: 2020.3.10f1)**  
- 2Dプロジェクトテンプレート  
- Rigidbody2D / Collider2D による物理挙動  
- タグ判定や GameObject の有効・無効化  
- **PostProcess演出**: Bloomを用いた柔らかな光の表現  
- **音楽と動きの調和**: ピアノ音の調べにあわせたインタラクション設計  

---

## 🎮 **プレイ方法**  
1. **スペースキー**でボールを発射（息吹の放出）。  
2. ブロック（魂）に光のボールを当てると、霧散し、新たな光となって昇華。  
3. ボールは背景に溶け込み、2～5秒後にピアノの音色に合わせ再び発射可能。  

🔸 **プレイ体験**：淡いピンクの光と清らかな音楽に包まれる儀式のようなゲームループを楽しめます。
